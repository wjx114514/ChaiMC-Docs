# 自己开一个服务器

> [!tip] 适用场景
> 想和朋友们拥有一个独立的 Minecraft 服务器，自由定制玩法与插件。

## 准备工作

> - [ ] 一台可长时间运行的电脑或云服务器（建议 4GB 内存以上）
> - [ ] 已安装对应版本的 [JAVA](/其他帮助/ii.JAVA的下载)
> - [ ] 服务端核心文件（如 Paper、Spigot、Fabric 等）

## 基础搭建步骤

### 1. 下载服务端

推荐使用 [PaperMC](https://papermc.io/)，性能优秀且支持插件：

- 前往官网下载对应 Minecraft 版本的核心 jar 文件
- 新建一个空文件夹（例如 `server`），将 jar 文件放入其中

### 2. 首次启动

在同目录下创建启动脚本 `start.bat`：

```bat
java -Xmx2G -jar paper.jar nogui
pause
```

> [!note] 参数说明
> `-Xmx2G` 表示分配 2GB 内存，可根据实际内存调整；`paper.jar` 替换为你下载的核心文件名。

首次启动会生成配置文件并自动退出，需要同意最终用户许可协议。

### 3. 同意 EULA

打开自动生成的 `eula.txt`，将 `eula=false` 改为 `eula=true`，保存后重新运行启动脚本。

### 4. 配置服务器

编辑 `server.properties` 常用选项：

| 配置项 | 说明 |
|---|---|
| `server-port` | 服务器端口（默认 25565） |
| `online-mode` | 是否开启正版验证 |
| `max-players` | 最大玩家数 |
| `motd` | 服务器列表中显示的简介 |

### 5. 连接服务器

- 本机连接：地址填 `localhost`
- 局域网连接：地址填开服电脑的内网 IP（`ipconfig` 查看）
- 公网连接：需要 [内网穿透](https://www.natfrp.com/) 或云服务器公网 IP

## 常见问题

> [!faq] 朋友无法连接？
> 检查防火墙是否放行 25565 端口，公网连接需配置内网穿透或使用云服务器。

> [!faq] 内存不足？
> 调整启动脚本中的 `-Xmx` 参数，建议分配物理内存的一半，且不超过 4GB（模组服可更高）。

> [!faq] 如何安装插件？
> 将插件 jar 文件放入 `plugins` 文件夹后重启服务器，Paper/Spigot 支持插件，Fabric 则需要安装 Fabric API 与模组。
