# 协助开发该文档

> [!tip] 关于本页面
> 该文档由社区共同维护，欢迎你参与到文档的编写和完善中来！

## 如何参与

### 提交反馈

> [!tip] 提交反馈
> 如果你在阅读过程中发现错误、遗漏或过时的内容，可以通过以下方式反馈：

- 在 GitHub 仓库提交 [Issue](https://github.com/wjx114514/ChaiMC-Docs/issues)
- 直接提交 Pull Request 修改内容

### 贡献内容

1. Fork [ChaiMC-Docs](https://github.com/wjx114514/ChaiMC-Docs) 仓库
2. 在对应目录下创建或编辑 `.md` 文件
3. 提交 Pull Request，等待审核合并

## 编写规范

> [!warning] 请遵循以下规范
> 保证文档风格统一，便于读者阅读和维护者管理。

- 使用 Obsidian 兼容的 Markdown 语法
- 文件名使用编号前缀排序
- 每篇文章开头添加与文件名一致的 H1 大标题

## 本地预览

在提交前，建议先在本地预览效果：

```bash
npm install
npm run docs:dev
```

打开浏览器访问 `http://localhost:5173/` 即可预览。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| [VitePress](https://vitepress.dev/) | 文档站点生成 |
| [Obsidian](https://obsidian.md/) | 文档编写工具 |
| [markdown-it-footnote](https://www.npmjs.com/package/markdown-it-footnote) | 脚注支持 |
| [markdown-it-mark](https://www.npmjs.com/package/markdown-it-mark) | `==高亮==` 标注支持 |
| [markdown-it-task-lists](https://www.npmjs.com/package/markdown-it-task-lists) | 复选框支持 |
