# 生存

> [!tip] 经典玩法
> 生存世界是服务器的主世界，在这里你可以体验几乎原汁原味的 Minecraft 生存。

## 保护你的家园

定居后，请使用领地系统防止他人破坏你的建筑
具体的领地指令请查看 [基本命令](/基础教程/4.基本命令)。

## 实用指令

| 指令 | 描述 |
|---|---|
| `/sethome [名字]` | 在当前位置设置家 |
| `/home [名字]` | 传送回家 |
| `/back` | 回到死亡点或上次传送位置 |
| `/tpa <玩家>` | 请求传送到其他玩家身边 |
| `/afk [原因]` | 标记挂机状态 |

## 玩家交易

- 使用 `/res market sell [领地名] [价格]` 出售领地
- 使用 `/bin` 打开垃圾桶获取 ~~被柴柴吃掉~~ 被清理的物品
- 使用 `/ca` 打开拍卖行，购买或出售物品
