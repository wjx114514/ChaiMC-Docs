# 给服务器新玩家的部分帮助

1.你可以使用`/menu`访问菜单，其中地标菜单由于bug暂时无法使用，请手动使用`/warp [地标名]`来传送地标（有关地标创建请咨询管理员）

2.玩家可以使用`/home`打开home GUI，默认玩家可以设置5个home

3._舰长_ [^1]可以使用`/fly`飞行且最多可以设置10个home
> [!important] 封禁申诉？
> 如果反作弊误封请向管理员申诉
4.由于ESSX插件更新，部分命令可能默认无权限，如果有必须的命令但无法使用（提示没有权限）（permission）可以于管理联系

5.如果有高频使用且无需参数（如坐标，玩家，标签等）的功能需要加入菜单可以联系管理员

6.服内设 _helper_ 权限组，可以报名加入，具体请联系管理员，_helper_ 可以使用corepretect插件的查询功能（即拥有`/co i`命令的权限），帮助查证物品放置/挖掘，容器储存/取出记录，如果较为严重，需要区域回档的，请联系管理员

7.服内管理员有 _admin/owner_ 前缀
[^1]: 斜体字代表权限组，下方的*helper*等亦如此
